# 4. Database and migrations

- **Status:** accepted
- **Date:** 2026-10-16

## Decision

- **Postgres 18 in Docker Compose**, accessed through **async SQLAlchemy 2 over asyncpg**.
- **One session per request** from a yield dependency. It never commits on its own: services
  commit explicitly, so transaction boundaries are visible in the code.
- **Schema conventions**: UUIDv7 primary keys generated by Postgres (time-ordered, so inserts
  stay at the end of the index and keyset pagination has a tie-breaker); `timestamptz`
  timestamps through a mixin; native enums storing their values; uniqueness enforced by
  constraints, never by a prior `SELECT`.
- **Deterministic constraint names** from a naming convention, so later migrations can alter
  constraints by name on every machine.
- **Alembic** with the URL from `Settings`. Autogenerate is a draft: every revision is read
  and its downgrade run before it is committed. Its blind spots are renames, enum changes,
  server defaults and anything SQLAlchemy does not model (it left an enum type behind on the
  first downgrade).
- **Enum changes are written by hand.** A revision creates and drops the Postgres type
  explicitly and declares its columns with `create_type=False`: within one Alembic run,
  SQLAlchemy skips creating a type name it has already created, even if it was dropped since.
- **Postgres extensions come from migrations**: the revision that first needs one creates it
  (`CREATE EXTENSION IF NOT EXISTS pg_trgm`) and its downgrade drops it. pg_trgm is a trusted
  extension, so the database owner can create it without superuser rights.
- **Local data is disposable** while nothing is deployed: a revision that reshapes a table may
  drop and recreate it instead of migrating rows, and says so in its docstring.

## Consequences

The engine is created at import, so one process talks to one database; asyncpg connections
belong to one event loop, which shapes the test setup.

## Alternatives considered

psycopg 3 (equally valid); UUIDv4 (random index inserts); a session that commits every
request (hidden boundaries).
